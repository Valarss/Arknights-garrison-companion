卫戍助手 · Arknights Garrison Companion

明日方舟卫戍协议助手，提供阵容攻略、实时建议与干员识别。 An Arknights Garrison Protocol companion for lineup guides, live recommendations, and operator recognition.

借鉴了几位大佬的作品和maa，加了点自己的想法整合了一下。

---

## 📖 项目介绍

卫戍助手是一个独立运行的「明日方舟 · 卫戍协议」辅助工具。

你可以通过侧边浮窗查看攻略、阶段拿牌、装备与升本建议，也可以结合游戏画面识别结果，参考当前持牌、商店商品、地图路线和站位建议。

支持原生 Windows PC 客户端，以及 MuMu 和其他主流 ADB 安卓模拟器的连接入口，无需整合进 MAA。

> 当前版本：**v0.8.0-preview.2**
>
> 本项目仍处于预览阶段。自动识别可能出现漏读或误判，路线与站位建议仅供参考，请以实际游戏画面为准。

## 🧩 阵容攻略与运营建议

### 分阶段查看攻略

内置 **22 条经过整理的攻略**，可以查看：

- 前期过渡与优先拿牌。
- 中期关键卡和阵容组成。
- 后期成型目标。
- 装备选择与运营说明。
- 攻略中已整理的升本节奏和启动条件。

干员旁会标注阶位，方便不熟悉卡池的玩家查阅。

### 主线与备线并行

可以同时关注主线和备线，结合实际来牌保留过渡方案。

系统会根据已确认持牌与商店信息，辅助提示其他可考虑的路线，避免只按一套阵容硬玩。**转阵提示不会自动替你切换攻略。**

### 根据本局禁用情况筛选

结合本局信息判断攻略是否可用：

- 必须依赖的核心条件被禁用时，排除对应路线。
- 非核心干员缺失时，保留存在替代空间的方案。
- 攻略中的不可用干员显示为红色，并以锁定叉号标记。

具体判断依赖攻略中已经整理的核心条件，不保证所有社区阵容都已完成同等程度的核验。

### 持牌标记

- **绿色**：已标记或确认拥有。
- **白色**：尚未确认拥有。
- **红色／锁定叉号**：本局不可用。

支持手动勾选已购买干员，也会结合有效的自动识别结果辅助更新。

## 🔍 自动观察与购买确认

### 对局信息读取

尝试从游戏画面中读取：

- 当前回合。
- 金币数量。
- 当前本数。
- 升级费用。
- 对局模式及部分策略信息。
- 盟约信息。
- 商店商品。
- 场上干员与部分装备状态。

不确定的身份会保留为候选或待确认，不直接当作可靠持牌。

### 商店购买确认

结合以下信息辅助判断购买：

1. 原有商品是否消失。
2. 对应位置是否出现空位。
3. 金币是否发生变化。
4. 连续画面是否支持同一判断。

购买确认与场上定位是两件事：确认买到某名干员，不代表已经准确识别其所在位置。

### 空闲自动查看干员详情

保留休整期空闲时自动查看干员详情的功能。

查看结束后会尝试点击右上角退出详情，继续后续观察；用户正在操作、目标窗口失去前台或无法核对目标时，助手会让位。

> 自动观察可能短暂打开游戏内详情界面，但不会自动购买、出售、移动干员或开始战斗。

## 🛡️ 棋盘、路线与站位

### 棋盘页面

查看识别到的干员、位置、阶位与身份候选，区分确认结果和待确认结果。

同时提供基于确认持牌的羁绊统计。统计可能包含备战区干员，**实际上场激活情况以游戏为准**。

### 地图路线提示

支持在游戏画面上显示当前识别地图的路线，辅助理解敌人的行进方向。

### 估算站位与朝向

根据有效的地图、回合与确认身份，在后台计算站位和朝向建议，并提供不同目标下的估算方案。

当地图、回合或阵容发生变化时，清理不适用的旧结果；停止识别后隐藏相关覆盖提示。

> 站位属于模拟估算，不保证最优。个人技能、模组、潜能、装备和实际战况可能与计算假设不同。

### 敌人与资金参考

提供可能出现的敌人组合、估算属性，以及下回合基础资金表参考。

基础资金参考不包含全部留存、策略和额外收益，不能直接理解为下一回合的最终余额。

## 🧰 干员、装备与敌人资料

### 干员图鉴

无需购买干员，也可以查询：

- 所属羁绊。
- 阶位。
- 普通与精锐被动效果。
- 本局禁用情况。
- 是否已确认拥有。

悬停干员可查看相关羁绊与效果说明，并可进入详情继续阅读。

### 装备资料

支持查看攻略装备推荐，以及参考数据中收录的装备效果、合成关系等信息。

### 敌人与策略资料

提供敌人基础属性、能力说明及部分策略资料，并保留已有的敌人详情和 PRTS 查询入口。

资料用于辅助查阅，内容与实际游戏版本不一致时请以游戏为准。

## 📥 阵容导入与计划编辑

### 外部阵容导入

保留兼容阵容 JSON、分享链接等导入入口，并支持从阵容站勾选批量导入。

导入时保留可获得的作者与原帖来源信息；公开阵容提供本地缓存，便于再次浏览。

### 不完整阵容的处理

阵容配方不一定是完整攻略。

只有成型阵容或简要思路的内容，导入后会进入攻略列表并标记为 **「待核验」**。缺失阶段、升本节奏和刚需条件不会被自动编造。

补齐并明确核验前，这类阵容不参与转阵推荐。

### 运营计划编辑

可以自行整理或调整：

- 前期、中期、后期的干员名单。
- 各阶段核心干员。
- “若干名干员中任选几名”的组合。
- 回合与升本计划。
- 阵容启动所需的核心条件。

编辑后的计划保存在本地，不直接覆盖原始攻略来源。

## 🪟 浮窗与界面

- **默认靠左停靠**，支持切换停靠方向。
- 常规宽度较上一版缩小约 **20%**。
- 支持置顶、透明度调整和拖动。
- 支持收起、展开与工作台视图。
- 鼠标在浮窗内可直接滚轮滚动。
- 棋盘随可用宽度缩放。
- 扫描时尽量只更新发生变化的内容，保留阶段选择、勾选与滚动位置，减少侧栏跳动。
- 可选择启用 Windows 本地语音提醒。

旧版右侧停靠设置会在本次更新首次启动时迁移到左侧，之后仍会保存自行切换的方向。

## 💾 本地记录与备份

- 保存本地对局与回合观察记录。
- 支持兼容配置、攻略计划等数据的备份和恢复。
- 备份只包含指定范围内的助手数据，不用于备份整个游戏或模拟器。
- 旧版目录可以保留，方便回退。

## 🖥️ 平台支持

提供以下连接入口：

- 明日方舟原生 Windows PC 客户端。
- MuMu 模拟器。
- 雷电、蓝叠、夜神、逍遥、应用宝等主流 ADB 模拟器。
- AVD 与通用 ADB 设备。

MuMu 保留增强截图支持，其他模拟器主要使用普通 ADB。

> 提供连接入口不代表全部平台的每项功能均已完成实战验证。原生 PC、其他模拟器、不同分辨率和多显示器环境仍需进一步测试。

## 🚀 安装与使用

### 下载运行

1. 在本仓库的 **Releases** 页面下载 Windows x64 完整运行包。
2. 完整解压到独立文件夹。
3. 启动 **卫戍助手.exe**。

**不要只复制 EXE，数据文件与运行库需要一起保留。**

### 开始一局

1. 打开游戏，进入卫戍协议。
2. 在助手中选择对应平台，连接并核对预览画面。
3. 模拟器用户确认 ADB 路径和设备选择正确。
4. 读取本局信息，选择主线与备线攻略。
5. 开启连续识别，在浮窗中查看拿牌、装备、运营及转阵参考。
6. 需要时打开棋盘、图鉴或资料页面。

开始下一局时，请使用 **「新一局」** 或重新读取本局信息，避免上一局的禁用与持牌状态影响判断。

### 更新版本

关闭旧版后，将新版完整解压到新目录运行。

请先保留旧版目录和个人配置备份。新版不会自动搬入旧版的全部私人设置，可通过兼容的备份恢复功能迁移相应数据。

## 🧪 当前验证情况与已知限制

### 已完成的验证

- v0.8.0-preview.1 的 **144 项相关回归测试通过**。
- 构建及离线侧栏、滚轮、刷新稳定性和平台切换检查通过。
- 保存的游戏截图中，成功读取回合和资金信息，并确认两名干员的购买结果。
- v0.8.0-preview.2 完成窄栏布局构建与离线侧栏检查。

### 仍需完善的部分

- 场上和备战区识别尚未完全可靠。
- 冻结卡、深色卡、遮挡和特殊界面可能影响识别。
- 实际游戏中的左侧贴边、覆盖对齐和连续自动查看仍需进一步实测。
- 站位建议依赖确认身份和参考数据，不保证最优。
- 本轮未完成全套测试，不能将相关测试通过理解为全部功能实战通过。

### 当前不包含

- 自动购买或出售。
- 自动部署、移动干员或开始战斗。
- 完整个人皮肤、技能、模组和潜能库存读取。
- 账号云同步。
- 拖拽棋盘进行完整试摆模拟。
